## ⚡ Comandos Rápidos de Git (Terminal)

> Abre la terminal integrada de IntelliJ (`Alt + F12`) en la raíz del proyecto.

### 🟢 Subir el proyecto por PRIMERA VEZ (desde cero)

```bash
git init
git add .
git commit -m "Initial commit: estructura base gestion_citas"
git branch -M main
git remote add origin [https://github.com/dlukaa/gestion_citas.git](https://github.com/dlukaa/gestion_citas.git)
git push -u origin main
```

### 🔄 UPDATE: Subir los cambios del día a día
```bash
git status
git add .
git commit -m "update: cambios en la interfaz y logica"
git push origin main
```
